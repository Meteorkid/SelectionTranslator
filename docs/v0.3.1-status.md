## 仍未完成 / 不能在本机完成

| 项目 | 类别 | 原因 |
| --- | --- | --- |
| Developer ID 公证 | 外部条件 | 本机只有 Apple Development 证书，没有 Developer ID Application；脚本已准备但无法执行 |
| Sparkle 自动下载安装 | 产品取舍 | 当前只做轻量 JSON 检查，不引入 Sparkle；要完整更新器需另做签名/回滚策略 |
| 真实 Anki 验收 | 外部条件 | 本机未安装 Anki.app，也没有 AnkiConnect；目前只有 mock 验证 |
| 20+ 翻译服务 | 大型产品取舍 | 需要每个服务独立的 Key、语言、限流、结果模型与设置 UI，不再是轻量 MVP |
| MDict / WebDAV / 插件系统 | 大型产品取舍 | 词典格式解析、同步冲突、插件沙箱都是独立子系统 |
| 多引擎并排对比 | 大型产品取舍 | 需要服务抽象、请求并发、结果对齐与 UI 重排；当前单主链路足够 |
| 静默 OCR 端到端 | 小缺口 | `⌥⇧S` 复制路径已实现；本轮只验证交互式 OCR，未单独回归静默复制 |

## 建议的下一步

1. 若要“能给别人下载”：先办 Developer ID，跑 `scripts/notarize.sh`，再做带 Sparkle 的正式更新源；打包前确认原生/液态玻璃两套主题的截图与包一致。
2. 若要“更像 Easydict”：优先做服务抽象与第二个服务适配器，不要先堆 20 个网站；其次才是 MDict/WebDAV。
3. 若要“更稳”：补静默 OCR 回归、真实 Anki 安装验收、Safari/Chrome 日常 profile 的安装说明截图。
